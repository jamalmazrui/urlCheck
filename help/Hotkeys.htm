urlCheck Hotkeys

The keys of the urlCheck dialog, listed three ways. Each Alt key is the letter underlined in its control’s label, so a screen reader reads it with the control. OK and Cancel have no letter: Enter is OK, Control+Enter is OK from any control, and Escape is Cancel. The dialog is built with the Homer Lbc classes, so every text field also has the Lbc editing keys; Help (F1) lists them.

By key

  • Alt+A — Authenticate credentials
  • Alt+B — Browse source
  • Alt+C — Choose output
  • Alt+Control+Shift+U — open the urlCheck dialog from anywhere (the desktop shortcut)
  • Alt+D — Default settings
  • Alt+F — Force replacements
  • Alt+G — Guide: open the full guide, then return to the dialog
  • Alt+H — Help
  • Alt+I — Invisible mode
  • Alt+L — Log session
  • Alt+M — Main profile
  • Alt+O — Output folder
  • Alt+S — Source urls
  • Alt+U — Use configuration
  • Alt+V — View output
  • Control+Enter — OK, from any control
  • Enter — OK: start the check
  • Escape — Cancel: close without checking
  • F1 — Help
  • F11 — check for a newer version
  • F7 — list the dialog’s controls, and move to the one chosen
  • Shift+F1 — say the focus tip for the current field

  5. Authenticate credentials — Alt+A
  6. Main profile — Alt+M

Why these keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because “elevate” sounds like “eleven”. Alt+Control+Shift+U belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts. U is the first letter of urlCheck. Shift is there because urlFido, the companion tool used more often, has Alt+Control+U: two shortcuts with one hotkey leave Windows to give it to whichever was made last.
