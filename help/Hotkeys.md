# urlCheck Hotkeys

The keys of the `urlCheck` dialog, listed three ways. Each Alt key is the letter underlined in its control's label, so a screen reader reads it with the control. OK and Cancel have no letter: Control+Enter is OK and Escape is Cancel, from any control, and Enter is OK except on a button. The dialog is built with the Homer Lbc classes, so every text field also has the Lbc editing keys; Help (F1) lists them.

## By key

- Alt+A — Authenticate credentials
- Alt+B — Browse local source
- Alt+C — Choose output directory
- Alt+Control+Shift+U — open the `urlCheck` dialog from anywhere (the desktop shortcut)
- Alt+D — Default settings
- Alt+F — Force replacements
- Alt+H — Help
- Alt+I — Invisible browser
- Alt+M — Main profile
- Alt+O — Output folder
- Alt+S — Source paths
- Alt+U — Use configuration
- Alt+V — View output directory
- Control+Enter — OK, from any control
- Enter — OK: start the check
- Escape — Cancel, from any control: close without checking
- F1 — Help
- F11 — check for a newer version, from any control
- F7 — list the dialog's controls, and move to the one chosen
- Shift+F1 — say the focus tip for the current field

## By command

- Authenticate credentials — Alt+A
- Browse local source — Alt+B
- Cancel — Escape
- Check for a newer version — F11
- Choose output directory — Alt+C
- Default settings — Alt+D
- Force replacements — Alt+F
- Help — Alt+H or F1
- Invisible browser — Alt+I
- List the controls — F7
- Main profile — Alt+M
- OK — Enter, or Control+Enter from any control
- Open the dialog from anywhere — Alt+Control+Shift+U
- Output folder — Alt+O
- Say the focus tip — Shift+F1
- Source paths — Alt+S
- Use configuration — Alt+U
- View output directory — Alt+V

## In tab order

The dialog is in bands, rows read left to right, in this order:

1. Source paths — Alt+S
2. Browse local source — Alt+B
3. Authenticate credentials — Alt+A
4. Invisible browser — Alt+I
5. Main profile — Alt+M
6. Output directory — Alt+O
7. Choose output directory — Alt+C
8. Force replacements — Alt+F
9. Use configuration — Alt+U
10. View output directory — Alt+V
11. Default settings — Alt+D
12. Help — Alt+H or F1
13. OK and Cancel, alone at the bottom right: Control+Enter is OK and Escape is Cancel, from any control

## Why these keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because "elevate" sounds like "eleven". Alt+Control+Shift+U belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts. U is the first letter of `urlCheck`. Shift is there because `urlFido`, the companion tool used more often, has Alt+Control+U: two shortcuts with one hotkey leave Windows to give it to whichever was made last.
